# 谷歌版《番茄小说》安装记

## 背景

- 阿里云盘里有个 **“谷歌三件套”** 文件夹（以前装过，留档备用）
- 爷嫌番茄小说**广告太多**，想给他装个**谷歌商店版**
- 但番茄（谷歌版）**不能独立于谷歌框架之外单独运行**，得先装三件套

## 折腾过程

1. **装三件套**：爷手机是安卓 15，下载“安卓 15”文件夹下的谷歌三件套 ✅
2. **登录美区谷歌账号**，商店搜索“番茄小说” → ❌ 搜不到
   - 疑问：是国际版整个下架了，还是美区单独下架？
   - 参考：以前给爸装过（爸手机装不了正规三件套，用的 **MicroG**，当时能装）
3. **改用 APKPure**：
   - 先装 APKPure 版番茄 → **卡开始界面**（现在想来是被“管制”了）
   - 辗转下载了 2 个 **XAPK 格式的非常规版番茄**（均未验证成功）
   - APKPure 安装谷歌版番茄 → 依然**卡开始界面**
4. **解除管制**：把“管制”相关的**禁止联网和其他限制全部取消** → ✅ 可用了

## 待验证

- [ ] APKPure 版番茄 + 无谷歌三件套，到底能不能用？

## 经验总结

### 1️⃣ 地区是隐形门槛

- 另一个**没设置过地区**的谷歌账号 → 能搜到番茄小说
- 该账号点击：**设置 → 常规 → 账号国家/地区** → 出现“推荐切换到香港 Play 商店”（当时用的香港节点）
- 美区账号同路径下，香港上方还有一个**打了勾的美国**
- 推测：**美区账号切换到香港 Play 商店后，大概率也能搜到番茄小说**

### 2️⃣ 道道真多，学会记录，以后不走弯路
