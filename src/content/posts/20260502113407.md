# 影视硬解 + 正版弹幕方案：弹弹play 下弹幕 → 转 ASS → PotPlayer 播放

## 痛点

弹弹play 因为要**实时渲染弹幕**，**不能用 GPU 硬解**，只能软解——

- 电脑温度顶不住 🌡️
- 而且会**很卡**

## 解决思路

> 弹幕和视频**分家**：弹幕转成字幕文件，交给支持硬解的播放器（PotPlayer）渲染。

1. **弹弹play 下载 XML 弹幕**
   - 弹弹play 能**嗅探正版视频网站的弹幕**
   - **VIP 影视剧的弹幕也可以**拿到 ✅
2. **转换弹幕格式**：XML 弹幕 → ASS 字幕
